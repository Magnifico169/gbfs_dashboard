## [Unreleased]

### Added
- ADR-0002 (итерация M0): языки R/Python, хранилище PostgreSQL 18, владение данными, pipeline, функции ролей, обработка ошибок оператора, цель по нагрузке — 1000+ одновременных пользователей.
- `docker-compose.yml` с PostgreSQL 18, healthcheck и шаблон `.env.example`.
- README: структура проекта, возможности, запуск, план вех.

### Changed
- Язык обработки данных — R (в первой версии концепта ошибочно значился Rust).
- Цель по нагрузке пересмотрена: вместо «сотен тысяч RPS» — устойчивость при 1000+ одновременных пользователей.
- Хранилище: ClickHouse отложен до результатов нагрузочного замера, всё хранится в PostgreSQL 18.
